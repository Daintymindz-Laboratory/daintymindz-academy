## A Data Operations Mindset

Good data operations work is not only about producing an output. It is about producing an output that other people can understand, verify, reproduce, and trust.

As you continue working with data, remember to:

1. Preserve the original source data.
2. Make cleaning rules explicit.
3. Treat missing or invalid values honestly.
4. Validate assumptions before relying on results.
5. Record what changed and why.
6. Build workflows that another person can run successfully.
