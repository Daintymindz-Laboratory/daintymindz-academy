# Python for Data Operations — Academy Coding Tests

Each file in this folder is arranged in the same order as the Academy Lesson Builder.

For every lesson:

1. Choose the course in **Admin → Lesson Builder**.
2. Create a lesson with type **Mini Project** and language **Python**.
3. Copy the **Instructions** and **Starter Code** sections.
4. Save the lesson.
5. Add each numbered test case using its **Description**, **Test Code**, and **Expected Output**.
6. Publish only after running the test cases against the instructor solution.

The test code prints `True` when the learner's function behaves correctly. Therefore every expected output is `True`.
