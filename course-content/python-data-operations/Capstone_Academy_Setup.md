# FreshLab Data Operations Capstone: Academy Setup

Create one **Project** lesson at the end of the Python for Data Operations course.

## Lesson settings

- Title: `Capstone: Build the FreshLab Dataset Pipeline`
- Type: `Project`
- Requires review: **On**
- Published: turn on only after the downloads and rubric are ready
- Instructions: paste the learner-facing content from `Capstone_Project_Brief.md`
- Rubric: select **Load rubric**

## Upload for students

Upload these in the lesson's **Student downloads** section:

1. `freshlab_pipeline_starter_kit.zip` — the main starter package
2. `Capstone_Project_Brief.md` — optional downloadable copy of the instructions

The starter ZIP should contain the stub `pipeline.py`, `test_acceptance.py`, fixtures, and the learner README template. Students download it, implement the pipeline locally, run the acceptance tests, then submit their repository or cloud-storage link for review.

## Keep instructor-only

Do **not** upload these as lesson resources:

- `INSTRUCTOR_pipeline_reference.py`
- `Capstone_Scoring_Rubric.md`

The reference implementation is the answer key. The rubric is already represented in the Academy's grading form and can remain in the instructor's private records.

## Grading

Open **Admin → Submissions**, select the learner's submission, record how many of the 11 acceptance tests pass, score the remaining rubric criteria, add feedback, and choose Pass, Revise, or Not yet.
